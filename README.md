## 🔭 Currently Working On

### 🏔️ Landslide Effect Detection

Working on detecting and analyzing the effects of landslides using **satellite imagery**.

The current work focuses on comparing satellite observations before and after a landslide event and exploring image-based indicators that can help identify affected regions.

**Working with:**

* 🛰️ Sentinel-2 satellite imagery
* 🌍 Remote sensing
* 🗺️ Geospatial data
* 📊 Image analysis
* 🤖 Machine Learning / Deep Learning

---

### 🌐 Extending Rajomon to HTTP Push

Working on an **ACN (Advanced Computer Networks)** project inspired by the ideas behind **Rajomon**.

The goal is to explore how the Rajomon approach can be extended to **HTTP Push**, studying its behavior and performance in this setting.

This involves working with:

* HTTP Push
* Network performance
* Request/response behavior
* Performance measurement
* Systems experimentation
